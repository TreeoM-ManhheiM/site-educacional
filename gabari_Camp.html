Códigos corretos – Loop Infinito Missão While (com comentários explicativos)
1. Contagem regressiva Missão 1
Use um loop `while` para exibir os números de 5 até 1 (decrescente).
contador = 5                     # começa com 5
while contador > 0:              # enquanto contador for maior que 0
    print(contador)              # imprime o número atual (5,4,3,2,1)
    contador -= 1                # decrementa 1 (contador = contador - 1)
2. Soma até 100 Missão 2
Some números de 1 até atingir ou ultrapassar 100. Exiba a soma final.
soma = 0                         # acumulador da soma começa vazio
numero = 1                       # primeiro número natural
while soma < 100:                # enquanto a soma não atingiu 100
    soma += numero               # adiciona o número atual à soma (soma = soma + numero)
    numero += 1                  # passa para o próximo número (numero = numero + 1)
print(soma)                      # exibe a soma final
3. Menu com Break Missão 3
Crie um loop infinito que pede um comando. Se digitar 'sair', use break.
while True:                      # loop infinito (roda para sempre até break)
    comando = input('Digite um comando (ou "sair"): ')   # lê o comando do usuário
    if comando == 'sair':        # se o comando for exatamente "sair"
        break                    # interrompe o loop imediatamente
    print(f'Você digitou: {comando}')  # senão, mostra o que foi digitado
4. Continue - Números ímpares Missão 4
Exiba apenas números ímpares de 1 a 10. Use continue para pular pares.
i = 1                            # começa em 1
while i <= 10:                   # enquanto i for menor ou igual a 10
    if i % 2 == 0:               # se i for par (resto da divisão por 2 é zero)
        i += 1                   # incrementa i (vai para o próximo número)
        continue                 # pula o resto do código, volta ao início do loop
    print(i)                     # imprime apenas os ímpares
    i += 1                       # incrementa i para o próximo

Peça um número e mostre sua tabuada do 1 ao 10 usando while.

9. Break - Encontrando primo Missão 9
Verifique se um número é primo. Se encontrar um divisor, use break.
num = int(input('Digite um número: '))   # número a testar
i = 2                            # começa do primeiro divisor potencial
while i < num:                   # enquanto i for menor que o número
    if num % i == 0:             # se i divide num exatamente (resto zero)
        print(f'{num} não é primo')   # não é primo
        break                    # interrompe (já achou divisor)
    i += 1                       # testa próximo divisor
else:                            # else do while (executa se não houve break)
    print(f'{num} é primo')      # se saiu sem break, é primo

13. Break e Continue combinados Missão 13
Percorra 1 a 50. Pule pares (continue). Se primo maior que 30, pare (break).
i = 1
while i <= 50:
    if i % 2 == 0:               # se for par
        i += 1
        continue                 # pula (não imprime)
    # verifica se é primo maior que 30 (simplificado: não divisível por 2,3,5)
    if i > 30 and i % 2 != 0 and i % 3 != 0 and i % 5 != 0:
        print(f'Primo encontrado: {i}')
        break                    # interrompe ao encontrar
    print(i)                     # imprime números ímpares não primos >30
    i += 1
14. Caixa eletrônico Missão 14
Saldo 1000. Saques: se insuficiente, continue; se 0, break.
saldo = 1000                     # saldo inicial
while True:                      # loop infinito
    saque = int(input('Digite o valor do saque (0 para sair): '))
    if saque == 0:               # se zero, encerra
        break
    if saque > saldo:            # se maior que o saldo
        print('Saldo insuficiente!')
        continue                 # volta ao início do loop, não faz o saque
    saldo -= saque               # subtrai o saque do saldo
    print(f'Saque realizado. Saldo atual: {saldo}')

16. Média de notas Missão 16
Peça notas até -1. Ignore negativas (continue). Calcule a média.
soma = 0
contador = 0
while True:
    nota = float(input('Digite a nota (-1 para sair): '))
    if nota == -1:               # sentinela de saída
        break
    if nota < 0:                 # se negativa, ignora
        continue
    soma += nota                 # acumula a nota válida
    contador += 1                # conta quantas notas foram somadas
if contador > 0:                 # se leu pelo menos uma nota
    media = soma / contador
    print(f'Média: {media:.2f}')
17. While aninhado com break Missão 17
i de 1 a 3, j de 1 a 5. Se j == 3, break interno.
i = 1
while i <= 3:                    # loop externo (i)
    j = 1
    while j <= 5:                # loop interno (j)
        if j == 3:
            break                # interrompe o loop interno
        print(i, j)              # imprime par (i,j)
        j += 1
    i += 1
18. Sequência de Fibonacci Missão 18
Gere Fibonacci até ultrapassar 1000. Pare quando termo > 1000.
a, b = 0, 1                     # primeiros termos: a=0, b=1
while a <= 1000:                 # enquanto o termo for <= 1000
    print(a)                     # mostra o termo
    a, b = b, a + b              # atualiza: a vira b, b vira a+b (próximo termo)

28. Soma dos dígitos Missão 28
Calcule a soma dos dígitos de um número positivo.
n = int(input('Digite um número: '))   # ex: 123
soma = 0
while n > 0:                          # enquanto ainda houver dígitos
    soma += n % 10                    # pega o último dígito (123 % 10 = 3) e soma
    n //= 10                          # elimina o último dígito (123 // 10 = 12)
print(f'Soma dos dígitos: {soma}')    # resultado: 1+2+3 = 6
29. Inverter número Missão 29
Inverta a ordem dos dígitos. Ex: 123 → 321.
n = int(input('Digite um número: '))   # ex: 123
invertido = 0
while n > 0:
    invertido = invertido * 10 + n % 10   # pega o último dígito e adiciona ao invertido
    n //= 10                              # remove o último dígito
print(f'Número invertido: {invertido}')   # 321
30. Desafio final Missão 30
Peça números até soma > 500 ou digitar -1. Mostre soma final.
soma = 0
while True:
    num = int(input('Digite um número (-1 para sair): '))
    if num == -1:                     # se for -1, sai
        break
    soma += num                       # acumula
    if soma > 500:                    # se ultrapassou 500
        break                         # sai também
    print(f'Soma atual: {soma}')      # mostra soma parcial
print(f'Soma final: {soma}')          # exibe o total
