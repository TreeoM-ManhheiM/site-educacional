Códigos corretos – Loop Infinito Missão While
1. Contagem regressiva Missão 1
Use um loop `while` para exibir os números de 5 até 1 (decrescente).
contador = 5
while contador > 0:
    print(contador)
    contador -= 1
2. Soma até 100 Missão 2
Some números de 1 até atingir ou ultrapassar 100. Exiba a soma final.
soma = 0
numero = 1
while soma < 100:
    soma += numero
    numero += 1
print(soma)
3. Menu com Break Missão 3
Crie um loop infinito que pede um comando. Se digitar 'sair', use break.
while True:
    comando = input('Digite um comando (ou "sair"): ')
    if comando == 'sair':
        break
    print(f'Você digitou: {comando}')
4. Continue - Números ímpares Missão 4
Exiba apenas números ímpares de 1 a 10. Use continue para pular pares.
i = 1
while i <= 10:
    if i % 2 == 0:
        i += 1
        continue
    print(i)
    i += 1
5. AND - Múltiplo de 3 e 5 Missão 5
Percorra números de 1 a 20. Pare ao encontrar um número divisível por 3 e por 5.
i = 1
while i <= 20:
    if i % 3 == 0 and i % 5 == 0:
        break
    print(i)
    i += 1
6. OR - Parada com 0 ou negativo Missão 6
Peça números até que o usuário digite 0 ou um número negativo. Use break.
while True:
    num = int(input('Digite um número (0 ou negativo para parar): '))
    if num == 0 or num < 0:
        break
    print(f'Você digitou: {num}')
7. NOT - Validação de senha Missão 7
Peça a senha. Enquanto a senha NÃO for '1234', continue pedindo.
senha = ''
while not senha == '1234':
    senha = input('Digite a senha: ')
print('Acesso liberado!')
8. Tabuada interativa Missão 8
Peça um número e mostre sua tabuada do 1 ao 10 usando while.
n = int(input('Digite um número: '))
i = 1
while i <= 10:

9. Break - Encontrando primo Missão 9
Verifique se um número é primo. Se encontrar um divisor, use break.
num = int(input('Digite um número: '))
i = 2
while i < num:
    if num % i == 0:
        print(f'{num} não é primo')
        break
    i += 1
else:
    print(f'{num} é primo')

12. Fatorial Missão 12
Calcule o fatorial de um número usando while.

fatorial = 1
original = n

13. Break e Continue combinados Missão 13
Percorra 1 a 50. Pule pares (continue). Se primo maior que 30, pare (break).
i = 1
while i <= 50:
    if i % 2 == 0:
        i += 1
        continue
    if i > 30 and i % 2 != 0 and i % 3 != 0 and i % 5 != 0:
        print(f'Primo encontrado: {i}')
        break
    print(i)
    i += 1
14. Caixa eletrônico Missão 14
Saldo 1000. Saques: se insuficiente, continue; se 0, break.
saldo = 1000
while True:
    saque = int(input('Digite o valor do saque (0 para sair): '))
    if saque == 0:
        break
    if saque > saldo:
        print('Saldo insuficiente!')
        continue
    saldo -= saque
    print(f'Saque realizado. Saldo atual: {saldo}')
15. Jogo da adivinhação Missão 15
Número secreto = 42. Peça palpites até acertar. Use break.
secreto = 42
while True:
    palpite = int(input('Adivinhe o número secreto: '))
    if palpite == secreto:
        print('Acertou!')
        break
    else:
        print('Tente novamente!')
16. Média de notas Missão 16
Peça notas até -1. Ignore negativas (continue). Calcule a média.
soma = 0
contador = 0
while True:
    nota = float(input('Digite a nota (-1 para sair): '))
    if nota == -1:
        break
    if nota < 0:
        continue
    soma += nota
    contador += 1
if contador > 0:
    media = soma / contador
    print(f'Média: {media:.2f}')
17. While aninhado com break Missão 17
i de 1 a 3, j de 1 a 5. Se j == 3, break interno.
i = 1
while i <= 3:
    j = 1
    while j <= 5:
        if j == 3:
            break
        print(i, j)
        j += 1
    i += 1
18. Sequência de Fibonacci Missão 18
Gere Fibonacci até ultrapassar 1000. Pare quando termo > 1000.
a, b = 0, 1
while a <= 1000:
    print(a)
    a, b = b, a + b

20. Login com tentativas Missão 20
3 tentativas. Use while, break se acertar, continue se errar.
tentativas = 0
while tentativas < 3:
    usuario = input('Usuário: ')
    senha = input('Senha: ')
    if usuario == 'admin' and senha == '123':
        print('Acesso liberado!')
        break
    else:
        tentativas += 1
        print(f'Senha incorreta! Tentativas restantes: {3 - tentativas}')
        continue
else:
    print('Conta bloqueada! Muitas tentativas.')

28. Soma dos dígitos Missão 28
Calcule a soma dos dígitos de um número positivo.
n = int(input('Digite um número: '))
soma = 0
while n > 0:
    soma += n % 10
    n //= 10
print(f'Soma dos dígitos: {soma}')
29. Inverter número Missão 29
Inverta a ordem dos dígitos. Ex: 123 → 321.
n = int(input('Digite um número: '))
invertido = 0
while n > 0:
    invertido = invertido * 10 + n % 10
    n //= 10
print(f'Número invertido: {invertido}')
30. Desafio final Missão 30
Peça números até soma > 500 ou digitar -1. Mostre soma final.
soma = 0
while True:
    num = int(input('Digite um número (-1 para sair): '))
    if num == -1:
        break
    soma += num
    if soma > 500:
        break
    print(f'Soma atual: {soma}')
print(f'Soma final: {soma}')
