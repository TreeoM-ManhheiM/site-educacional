Aula 1 – Introdução ao Feature Engineering

A Engenharia de Atributos consiste no processo de transformar dados brutos em variáveis preditivas para alimentar algoritmos de Machine Learning.

1. Atributos Irrelevantes / Redundantes
  • ID_Cliente / pedido_id: Apenas identificadores cadastrais sem padrão preditivo real.
  • produto_id: Redundante quando já possuímos a categoria_produto.
  • tipo_dispositivo: Pouco impacto direto na análise de risco financeiro.
2. Propostas de Novas Features
  • RendaPorLimiteCartao: Mede a proporção do limite concedido em relação aos ganhos mensais.
  • PercentualSaldo: Percentual da renda mantido como saldo em conta.
  • TempoComoCliente: Medida em anos de engajamento com a instituição.

Aula 4 – Modelos de Classificação Supervisionada

Treinamento e comparação entre Regressão Logística e Árvores de Decisão para predição de inadimplência.

# Roteiro de Modelagem (Classificação)
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.tree import DecisionTreeClassifier
from sklearn.metrics import accuracy_score

df = pd.read_csv('dados_banco_alpha_modificado.csv')

X = df.drop(columns=['AtrasoPagamento'])
y = df['AtrasoPagamento']

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.20, random_state=42)

# Treinamento dos Classificadores
lr_model = LogisticRegression(max_iter=1000).fit(X_train, y_train)
dt_model = DecisionTreeClassifier(max_depth=5, random_state=42).fit(X_train, y_train)

# Avaliação Inicial
print("Acurácia Regressão Logística:", accuracy_score(y_test, lr_model.predict(X_test)))
print("Acurácia Árvore de Decisão:", accuracy_score(y_test, dt_model.predict(X_test)))

Aula 5 – Métricas e Avaliação de Desempenho

Diagnóstico aprofundado com Matriz de Confusão, Precision, Recall e Curva ROC-AUC.

import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier
from sklearn.metrics import classification_report, confusion_matrix

df = pd.read_csv('dados_banco_alpha_modificado.csv')
X = df.drop(columns=['AtrasoPagamento'])
y = df['AtrasoPagamento']

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.20, random_state=42)
model_dt = DecisionTreeClassifier(random_state=42).fit(X_train, y_train)
pred_dt = model_dt.predict(X_test)

print("=== Relatório de Classificação ===")
print(classification_report(y_test, pred_dt))

print("=== Matriz de Confusão ===")
print(confusion_matrix(y_test, pred_dt))

Aula 6 – Ensembles & Otimização de Hiperparâmetros

Aumento da capacidade preditiva com Random Forest e busca exaustiva via GridSearchCV.

import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier

df = pd.read_csv('dados_banco_alpha_modificado.csv')
X = df.drop(columns=['AtrasoPagamento'])
y = df['AtrasoPagamento']

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.20, random_state=42)

rf = RandomForestClassifier(n_estimators=50, random_state=42)
rf.fit(X_train, y_train)

importances = pd.Series(rf.feature_importances_, index=X.columns).sort_values(ascending=False)
print("=== Relevância das Variáveis no Ensemble ===")
print(importances)
