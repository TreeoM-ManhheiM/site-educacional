SEMANA 2 - Sistema de Vendas

Descrição da Atividade:
Você vai criar um sistema para calcular o valor final de uma venda em uma loja, aplicando regras de negócio para descontos e frete.

Regras do Negócio:

  • Desconto de 5% para compras acima de R$100,00.
  • Desconto de 10% para compras acima de R$500,00.
  • Frete fixo de R$15,00 para compras com valor total abaixo de R$200,00.

Requisitos do Algoritmo:

  1. Leia o valor total dos produtos (subtotal).
  2. Calcule o desconto apropriado com base no valor.
  3. Adicione o frete se o valor for menor que R$200,00.
  4. Mantenha a exibição de:
    • Subtotal;
    • Desconto aplicado;
    • Valor do frete;
    • Total final.

Código Python:

valor = float(input("Valor da compra: R$ "))

desconto = 0.0

if valor > 500:
    desconto = valor * 0.10
elif valor > 100:
    desconto = valor * 0.05

frete = 0.0

if valor < 200:
    frete = 15.0

total = valor - desconto + frete

print(f"Subtotal: R$ {valor:.2f}")
print(f"Desconto: R$ {desconto:.2f}")
print(f"Frete: R$ {frete:.2f}")
print(f"Total Final: R$ {total:.2f}")

SEMANA 5 - Integrando Estrutura Sequencial com o Comando SE (Calculadora de Média)

Descrição da Atividade:
Você deve criar um programa que leia duas notas de um aluno, calcule a média aritmética e verifique se o aluno foi aprovado ou não. A média mínima para aprovação é 6.0.

Instruções para Realização da Atividade:

  1. Declare as variáveis para armazenar as duas notas e a média.
  2. Solicite e leia as duas notas do usuário.
  3. Calcule a média aritmética das notas: media = (nota1 + nota2) / 2.
  4. Exiba a média calculada no console.
  5. Use a estrutura SE (if) para verificar se a média é maior ou igual a 6.0.
  6. Se for verdadeiro, exiba a mensagem "Aprovado". Caso contrário, exiba "Reprovado".

Código Python:

nota1 = float(input("Digite a primeira nota: "))
nota2 = float(input("Digite a segunda nota: "))

media = (nota1 + nota2) / 2

print(f"Média calculada: {media:.1f}")

if media >= 6.0:
    print("Situação: Aprovado")
else:
    print("Situação: Reprovado")

  3. Utilizem as ferramentas para implementar o algoritmo de ordenação.

Código Python:

# Exemplo do algoritmo de ordenação Bubble Sort em vetores
numeros = [5, 2, 8, 1, 9]
tamanho = len(numeros)

for i in range(tamanho):
    for j in range(0, tamanho - i - 1):
        if numeros[j] > numeros[j + 1]:
            numeros[j], numeros[j + 1] = numeros[j + 1], numeros[j]

print("Lista ordenada:", numeros)

    return sum(notas) / len(notas)

    if media >= 6.0:
        print("Status: Aprovado")
    else:
        print("Status: Reprovado")

# Mini-projeto modularizado integrando funções e estruturas de controle
def exibir_menu():
    print("\n--- SISTEMA MODULAR ---")
    print("1 - Adicionar item")
    print("2 - Listar itens")
    print("0 - Sair")

def sistema_principal():
    itens = []
    opcao = -1
    
    while opcao != 0:
        exibir_menu()
        opcao = int(input("Escolha uma opção: "))
        
        if opcao == 1:
            novo_item = input("Digite o nome do item: ")
            itens.append(novo_item)
            print("Item adicionado com sucesso!")
        elif opcao == 2:
            print("\nItens cadastrados:", itens)
        elif opcao == 0:
            print("Encerrando o sistema...")
        else:
            print("Opção inválida!")

# Inicialização do programa
sistema_principal()
